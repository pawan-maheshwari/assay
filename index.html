Test the claim, not the press release.

Every release note says faster, cheaper, smarter. Assay turns each of those lines into a measurable hypothesis, runs the old and new model on identical tasks, and stamps a verdict only when the difference is bigger than run-to-run noise.

Tokens are not a shared currency

"Fewer tokens" can just mean a different tokenizer. Assay compares cost per completed task instead.

Reasoning is billed, not shown

A lower price per token can still mean a bigger bill. Assay counts reasoning tokens when the API reports them.

Small gaps are often noise

A 3-point gain on 20 questions proves nothing. Assay marks overlapping results as inconclusive.

How verdicts are stamped

Named after the hallmarks an assay office puts on precious metal once it has tested what the seller said it was.

Validation guide

Every number on a verdict comes from four steps. Each step below is live: change the inputs and watch the maths, the chart and the stamp respond.

1

Turn the claim into a percentage

A claim only counts when it compares the same thing before and after. For costs, tokens and latency, lower is better, so the improvement is how much smaller the new number is. For speed, higher is better. For accuracy and benchmark scores, Assay uses the plain difference in points, because "20% more accurate" on a 50% base and on a 90% base mean very different things.

2

Price the work, not the token

A task's cost is input tokens times the input price plus output tokens times the output price. Output includes reasoning tokens you never see. Dividing by accuracy gives the cost per correct answer, which is what you actually pay for a usable result.

3

Check it is bigger than noise

Models give different answers run to run, and a small task set can make a coin flip look like progress. Assay resamples your tasks 800 times with replacement (a paired bootstrap), recomputes the difference each time, and keeps the middle 95% as the range. If that range crosses zero, the change could be luck.

Each run draws new random answers.

4

Stamp the verdict

Delivered is the measured improvement divided by the claimed one. The rules run in order and stop at the first that applies, and a quality check can downgrade a cost or speed win that came from worse answers.
